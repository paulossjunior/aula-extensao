# Aula 04 — Identificação de Clientes

**Data:** 24/08/2026 | **Horário:** 11h20 às 13h00 | **Local:** Lab 207 | **Modalidade:** Presencial

---

## Introdução

Nas aulas anteriores cada grupo chegou a um problema e a uma hipótese de valor. Falta responder a uma pergunta que decide o resto do projeto: **para quem, exatamente, esse problema é um problema?**

Um erro comum é responder "para todo mundo". Público amplo demais gera produto genérico, mensagem fraca e validação impossível. Nesta aula vamos estreitar o foco: separar quem *usa* de quem *paga* e de quem *decide*, escolher um **segmento-alvo** e descrever o **early adopter** — a pessoa que sente a dor com intensidade suficiente para topar usar uma solução ainda imperfeita.

---

## Discovery do Projeto

Identificar clientes é trabalho de discovery, não de marketing. Trabalharemos três frentes:

- **Mapa de Atores**
  Nem todo envolvido é cliente. Em um mesmo problema costumam coexistir papéis distintos: quem usa, quem paga, quem decide, quem influencia e quem é afetado sem participar. Confundir esses papéis leva o grupo a construir para a pessoa errada.

- **Segmentação**
  Quebrar o público amplo em grupos menores e homogêneos, com contexto, rotina e restrições parecidas. Um bom segmento é **descritível, alcançável e mensurável**: você consegue dizer quem é, sabe onde encontrá-lo e consegue contar quantos são.

- **Perfil do Early Adopter**
  Dentro do segmento escolhido, quem sofre mais e já tenta resolver a dor por conta própria — com planilha, caderno, grupo de WhatsApp, gambiarra. Quem já improvisa uma solução é quem valida mais rápido.

### Papéis a distinguir

| Papel        | Pergunta que identifica                       |
|--------------|-----------------------------------------------|
| Usuário      | Quem vai operar a solução no dia a dia?       |
| Cliente/Pagador | Quem arca com o custo, em dinheiro ou tempo? |
| Decisor      | Quem autoriza a adoção?                       |
| Influenciador| Quem a pessoa consulta antes de decidir?      |
| Afetado      | Quem sente o resultado sem usar o produto?    |

!!! tip "Critério de Segmento Útil"
    Se o grupo não consegue apontar **onde encontrar cinco pessoas desse segmento até a próxima aula**, o segmento ainda está largo demais.

### Perguntas Norteadoras

1. Quem sente essa dor com mais frequência e mais intensidade?
2. O que essa pessoa faz hoje para contornar o problema?
3. Quanto o problema custa a ela — em tempo, dinheiro, risco ou desgaste?
4. Quem paga pela solução é a mesma pessoa que a usa? Se não, o que muda?
5. Onde essas pessoas se encontram — fisicamente ou online?
6. Existe alguém que **perde** algo se o problema for resolvido?

!!! warning "Cuidado: Público Genérico"
    "Pequenos empreendedores", "estudantes" e "a comunidade" não são segmentos — são categorias. Segmento é "aluno de graduação no último período que precisa validar horas de trabalhos complementares e hoje envia comprovantes por e-mail para a coordenação".

## Tarefas

### Tarefa 1 — Mapa de Atores

**Duração estimada:** 20 min
**Formato:** Grupos

A partir do problema priorizado, cada grupo deve listar **todos** os envolvidos e classificar o papel de cada um.

| Ator | Papel | O que ganha ou perde com a solução |
|------|-------|-------------------------------------|
|      |       |                                     |
|      |       |                                     |
|      |       |                                     |

Registrem no mínimo quatro atores e indiquem qual deles é o **usuário principal**.

**Entregável:** Mapa de atores preenchido com o usuário principal destacado.

---

### Tarefa 2 — Segmentação e Escolha do Alvo

**Duração estimada:** 20 min
**Formato:** Grupos

Quebrem o público amplo em ao menos **três segmentos** distintos e escolham um para focar.

| Segmento | Contexto e rotina | Intensidade da dor (1–5) | Facilidade de acesso (1–5) |
|----------|-------------------|--------------------------|-----------------------------|
|          |                   |                          |                             |
|          |                   |                          |                             |
|          |                   |                          |                             |

Escolham o segmento com melhor combinação entre **dor alta** e **acesso fácil** — dor alta sem acesso não permite validar nada neste curso.

**Entregável:** Segmento-alvo escolhido com justificativa de duas linhas.

---

### Tarefa 3 — Perfil do Early Adopter

**Duração estimada:** 20 min
**Formato:** Grupos

Descrevam **uma pessoa concreta** do segmento escolhido. Nome fictício, mas comportamento real, baseado em evidência e não em suposição.

Preencham:

- **Quem é:** perfil, faixa etária, ocupação
- **Contexto de uso:** onde e quando o problema aparece na rotina
- **Solução atual:** o que a pessoa já faz hoje para contornar a dor
- **Gatilho:** o que a faria experimentar algo novo
- **Objeção:** o que a faria desistir

**Entregável:** Perfil de early adopter documentado.

---

### Tarefa 4 — Síntese para o PRD

**Duração estimada:** 15 min
**Formato:** Grupos

Transformem o resultado das tarefas anteriores na seção **Público-alvo** do [Template de PRD](../../modelos/prd-template.md), preenchendo Perfil, Faixa etária, Contexto de uso e **Benefícios esperados do produto**.

**Entregável:** Seção 2 do PRD preenchida.
